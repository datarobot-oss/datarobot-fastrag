# ---------------------------------------------------------------------------
# Extra Python dependencies for this fastrag execution environment.
#
# datarobot-fastrag is installed from a local wheel (see install_dependencies.sh)
# and pulls its FULL required dependency closure automatically, including
# datarobot-moderations (core) and, transitively:
#   fastapi, uvicorn, starlette, pydantic, pydantic-settings, openai, httpx,
#   opentelemetry-*, numpy, pandas, tiktoken, rouge-score, nltk, requests, ...
# So none of those need to be listed here.
#
# This is a MINIMAL env. The heavy "batteries" that the official
# [GenAI] Python 3.12 with Moderations environment ships -- torch, transformers,
# sentence-transformers, faiss, onnx/onnxruntime, optimum, scikit-learn, scipy,
# langchain*, llama-index, nemoguardrails, google-cloud-aiplatform, and the
# vector-DB clients -- and DataRobot MLOps monitoring are intentionally excluded.
#
# Add per-model dependencies below (or ship them in the model's own
# requirements). Moderation guards that rely on optional features need the
# matching datarobot-moderations extras, e.g.:
#   datarobot-moderations[llm-eval]        # LLM-as-judge / faithfulness metrics
#   datarobot-moderations[nemo]            # NeMo Guardrails
#   datarobot-moderations[vertex]          # Vertex AI provider for guards
#   datarobot-moderations[datarobot-sdk]   # guards backed by DataRobot deployments
# ---------------------------------------------------------------------------

# Cap openai below 3.0. fastrag depends on `openai>=2.20.0` (open-ended), but
# openai 3.0.0 is a breaking major that swapped its `httpx` dependency for an
# `httpx2` fork -- so an unpinned resolve drops the `httpx` module the runtime
# needs and pulls an openai version fastrag was not built against. Staying on 2.x
# keeps real httpx and matches the tested SDK.
openai>=2.20.0,<3

# httpx is required at runtime (openai 2.x uses it internally). Listed explicitly
# so it is guaranteed present regardless of openai's transitive dependency choices.
httpx>=0.28,<1

# ---------------------------------------------------------------------------
# Monitoring -- Python-only (no embedded Java MLOps agent).
#
# datarobot-moderations reports guard/moderation events through the DataRobot
# SDK's datarobot.mlops.events API (its `datarobot-sdk` extra = datarobot +
# datarobot-predict), and datarobot-mlops adds prediction/drift reporting from
# the model. All three are pure Python (~33 MB total); the model reports to
# DataRobot directly or via a platform-run agent, so no JRE / agent jar is baked
# into the image. DataRobot injects MLOPS_DEPLOYMENT_ID / MLOPS_MODEL_ID and the
# spooler configuration at deploy time -- nothing to set here.
datarobot>=3.6              # provides datarobot.mlops.events (moderation events)
datarobot-predict>=1.9.6    # pairs with the datarobot SDK (datarobot-sdk extra)
datarobot-mlops==11.2.42    # prediction / drift reporting
# ---------------------------------------------------------------------------
