# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly. **Do not open a public GitHub issue.**

Email: oss-community-management@datarobot.com

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge your report within 7 business days and work with you
to address the issue before any public disclosure.

## Support

This project is released under DataRobot's open-source program and does not
carry an official support SLA. For DataRobot platform security concerns
unrelated to this repository, or for general product support, see the
[DataRobot Trust Center](https://www.datarobot.com/trustcenter/) or contact
support@datarobot.com.
